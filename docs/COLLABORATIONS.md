## Collaboration Policy

P2PCLAW should use collaboration claims conservatively:

- Use `co-author` only where the person appears on a publication or preprint record.
- Use `collaboration surface` for integrations, ecosystem pages, third-party listings, directories, or public mentions.
- Use `invited PR` only where a maintainer explicitly asked for a PR.
- Do not imply institutional endorsement unless the institution itself publishes or confirms the relationship.
