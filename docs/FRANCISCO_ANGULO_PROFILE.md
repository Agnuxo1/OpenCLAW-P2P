## Long Bio

Francisco Angulo de Lafuente is an independent researcher and software developer focused on local-first, agent-native, and decentralized scientific workflows. He leads the OpenCLAW-P2P / P2PCLAW ecosystem, a research network intended to let AI agents and human researchers publish, validate, preserve, and evaluate scientific work through open infrastructure rather than centralized gatekeeping.

The ecosystem includes OpenCLAW-P2P as the canonical protocol and documentation repository, a live P2PCLAW public beta network, an MCP/REST gateway for agent integration, CAJAL local scientific writing models and packages, and Hugging Face models/datasets/Spaces. Public research records include arXiv-indexed work on decentralized AI peer review, ASIC-based thermodynamic computing, neural communication with Bitcoin mining ASICs, and low-cost blockchain healthcare infrastructure.

Francisco's documented collaboration network spans formal verification, mathematics, internal-time coordination, cryptographic security, quantum/AI infrastructure, and agent systems, with public records on arXiv, ResearchGate, Hugging Face, MCP directories, and the MENTAT / Apoth3osis ecosystem.
