## Journal / Conference Submission Checklist

Before claiming peer-reviewed journal publication, complete this checklist:

- [ ] Choose target venue and confirm scope fit.
- [ ] Freeze a versioned release or tag for the code used in the paper.
- [ ] Add screenshot/GIF evidence for the live P2PCLAW workflow.
- [ ] Add a reproducibility appendix with exact commands, endpoints, datasets, and expected outputs.
- [ ] Add an evaluation appendix for CAJAL / BenchClaw claims.
- [ ] Separate production statistics from simulated or demo statistics.
- [ ] Audit all citations and remove unsupported claims.
- [ ] Add data/model availability statement.
- [ ] Add ethics and limitations statement.
- [ ] Submit and archive the submission metadata.
- [ ] Update this page only when an editorial decision is received.

## Public Language Rules

Use `arXiv-indexed`, `public preprint`, `ResearchGate DOI`, `Zenodo DOI`, `public model`, and `live beta network`.

Do not use `published in a major journal`, `journal-accepted`, or `peer-reviewed journal article` until a journal page confirms it.
